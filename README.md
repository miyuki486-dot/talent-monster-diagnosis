# 才能モンスター発見！博士ちゃん診断

「こども起業家研究所 ～博士ちゃんラボ～」の親子向け診断ツールです。

公開サイト: https://miyuki486-dot.github.io/talent-monster-diagnosis/

## 公開方法

`main` ブランチへ更新を送ると、GitHub Actionsが `dist/` の静的サイトをGitHub Pagesへ公開します。

## 現在のテスト仕様

- 回答者→モンスター表示→星座＋性格4問＋好き3問で12タイプを判定
- 7問の回答から文章パーツを組み合わせ、メイン＋サブタイプや声かけを個別表示（AI利用料なし）
- 男女それぞれ12タイプ×4段階の正式素材を使用し、卵だけカラー、進化後3段階はシルエット表示
- 「答えたくない／その他」は、判定後に男女2つの卵から相棒を選べる
- Webでは簡易結果を表示し、受取コードを公式LINEへ送ると個別の詳細結果URLを受け取れる
- 詳細診断は個別URLからWebで閲覧できる（PDF保存・印刷ボタンは調整完了まで一時非表示）
- 詳細シートは黄色・水色・ピンクを基調にし、「親子で話してみよう」まで1枚に掲載
- 子ども回答では、最初に保護者の簡単な確認を入れる
- 受取コードと個別結果URLは30日、受取用データは90日で削除する
- 自由回答やLINE識別値を含まない匿名の分析データだけを長期保存する
